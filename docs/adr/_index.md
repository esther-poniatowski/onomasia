# Architecture decisions

Records the decisions binding later work on Onomasia, so that a reader can judge whether a changed constraint reopens one of them.

- [Formats and contracts](formats-and-contracts.md): records the founding choices of Onomasia, and the options weighed against them
- [Text checks](text-checks.md): records how Onomasia checks a text against the records bound to it
- [Imports across repositories](imports-across-repositories.md): records how a glossary imports the entries of a glossary of another repository at a selected state
- [Unit targets](unit-targets.md): records how a notation names its unit as a logical target, and how the outputs carry it
